Video Editor (Performance Ads + Organic)

Goal: consistent output → 30 videos/month

Brief

Role

Edit short-form vertical content for Meta/TikTok/Reels. Mix of meme-style educational + direct response ads. Must be fast, consistent, and performance-minded.

Output volume

  • • Phase 1: 8–12 videos/month (one per offer)
  • • Phase 2: 30 videos/month (steady cadence)
  • • Turnaround: 24–72 hours per batch

Formats

  • • 9:16 (1080×1920), 15–45s
  • • Subtitles baked in (clean, readable)
  • • Hook text in first 1–2 seconds

Must-haves

  • • Proven short-form portfolio (ads preferred)
  • • Understand pacing, retention, pattern interrupts
  • • Can follow a template system + naming conventions
  • • Reliable: hits deadlines, communicates issues early

Paid test (required)

We will provide raw footage + script. You deliver:

  • • 1 × 20s direct-response edit
  • • 1 × 30s meme/educational edit
  • • 3 hook variations each (text overlay changes + first 3 seconds variations)

Application questions

  1. 1) Link 3 best short-form edits (ads preferred)
  2. 2) What’s your typical turnaround for 10 videos?
  3. 3) What tools do you use (CapCut/Premiere/AE/DaVinci)?
  4. 4) Have you edited for service businesses before?
